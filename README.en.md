# 小番茄程序猿 · Personal Website

A fully static (HTML / CSS / JS, **zero-build, zero-dependency**) personal portfolio + tech blog + deep-dive column. Deployable to GitHub Pages for free, or just open `index.html` locally.

## Pages

| Page | File | Content |
| --- | --- | --- |
| Home | `index.html` | Profile snapshot, featured projects, blog preview, contact |
| Projects | `projects.html` | High-concurrency backend family (Redis / MySQL / Spring Cloud / ES / K3s / Jeepay / k6 / seckill) + AI Agent family (Spring AI phase1→6 + rdx-agent) |
| Blog | `blog.html` | Canonical posts cross-published on CSDN / Juejin / Zhihu; Markdown sources in `blog/` |
| Deep | `deep.html` | Low-level principles column: 105 docs across 6 series (MySQL / Redis / ES / benchmarking / K8s / Agent); sources in `deep/` |

## Local preview

```bash
python -m http.server 8080
# open http://localhost:8080
```

Blog and deep-dive docs are provided as Markdown source — clicking a link opens the corresponding `.md` file.

## Deploy to GitHub Pages

1. Push to the default branch (`main`):

   ```bash
   git add .
   git commit -m "personal site"
   git push -u origin main
   ```

2. Repo **Settings → Pages → Source**: `main` branch, `/root`.
3. Visit `https://<username>.github.io`.

## Comments (Giscus)

The site-wide "交流区" uses [Giscus](https://giscus.app) (GitHub Discussions, no ads / no tracking). To enable: turn on Discussions, install the Giscus App, then fill `repo-id` / `category-id` into `CONFIG` at the top of `assets/js/comments.js`.

Until configured, the comment area shows a hint and does not affect page rendering.

## Notes

- Pure static, relative paths — works on GitHub Pages or any static host.
- No framework, no build step.
- `deep.html` is generated by `gen_deep.py`; re-run it after adding `.md` docs under `deep/`.
