About

Hi, I'm Li Yonggui

A backend developer working on two things: high-concurrency Java systems and AI Agent engineering. Based in China, writing in Chinese — but the code, benchmarks and numbers are universal.

On one side: load testing, tuning and capacity planning for Redis / MySQL / Spring Cloud microservices — every claim on this site is backed by reproducible benchmark commands and measured numbers, not opinions.

On the other: a complete engineering progression with Spring AI — from a minimal agent to RAG, MCP tool integration and evaluation systems. I care about things that run and are measurable, not concept demos.

This site hosts 100+ long-form articles and deep-dive handbooks, all open source on GitHub. Most articles are written in Chinese — if you read code and commands better than prose, you'll still get most of the value.
