AI Agent 学习线路：
从原理到生产实战的 8 站。

这条线路把本站全部 10 篇 AI Agent 文章按「认知顺序」重新组织：8 站主线路建议按顺序读——每一站回答一个问题：读完它你能解决什么；另有 2 篇随查手册放在最后，工作中直接翻，不必按顺序。

适合谁调过 LLM API 但没系统化工程化的开发者；想把 Agent 从 demo 推向生产、关心护栏/成本/评测的人。
前置知识会用 Java 或 Python 调用 LLM 接口，理解 prompt 与函数调用的基本概念；不需要框架使用经验。
完成标准能独立搭建带舱壁护栏、语义缓存与熔断的 Agent 服务；能设计 RAG 评测集并接入 CI 质量门禁；能用 MCP 把工具接入协议化。
