1. 分片路由与倾斜排查命令

查看文档归属分片

GET /索引名/_search?routing=路由值
{
 "_size": 1,
 "_source": false
}

查看索引分片分布

GET _cat/shards/索引名?v

查看索引自定义路由开启状态

GET 索引名/_mapping?filter_path=*.routing

统计各分片文档数量（判断倾斜）

GET 索引名/_search
{
 "size": 0,
 "aggs": {
 "shard_group": {
 "terms": {
 "script": {
 "source": "doc['_shard_id'].value"
 },
 "size": 20
 }
 }
 }
}

2. 集群分片均衡 & 磁盘水位配置

设置分片搬迁并发与限速（生产常用）

PUT _cluster/settings
{
 "transient": {
 "cluster.routing.allocation.node_concurrent_incoming_recoveries": 2,
 "cluster.routing.allocation.node_concurrent_outgoing_recoveries": 2,
 "cluster.routing.allocation.cluster_concurrent_rebalance": 2,
 "indices.recovery.max_bytes_per_sec": "40mb"
 }
}

临时关闭集群自动均衡（高峰期防IO抖动）

PUT _cluster/settings
{
 "transient": {
 "cluster.routing.allocation.allow_rebalance": "none"
 }
}

恢复自动均衡

PUT _cluster/settings
{
 "transient": {
 "cluster.routing.allocation.allow_rebalance": "indices_all_active"
 }
}

查看磁盘水位阈值配置

GET _cluster/settings?include_defaults=true&filter_path=*.disk.watermark

3. ILM 生命周期常规运维命令

查看索引 ILM 流转详情、卡住原因

GET 索引名/_ilm/explain

暂停单个索引 ILM

POST 索引名/_ilm/stop

开启单个索引 ILM

POST 索引名/_ilm/start

全局启停所有 ILM

POST _ilm/stop
POST _ilm/start

查看全局 ILM 巡检间隔

GET _cluster/settings?include_defaults=true&filter_path=indices.lifecycle.poll_interval

修改 ILM 全局巡检间隔

PUT _cluster/settings
{
 "transient": {
 "indices.lifecycle.poll_interval": "5m"
 }
}

查询所有绑定 ILM 的索引

GET _settings/index.lifecycle.name:*

4. ILM 冷热层级向上回退全套通用命令

通用前置：查看分片回迁进度统一命令

GET _cat/recovery?v&h=index,shard,percent,source_node,target_node,stage

场景1：Warm → Hot 温层回退热层

# 修改层级标签，触发分片回迁
PUT 索引名/_settings
{
 "index.routing.allocation.data_tier": "hot"
}
# 暂停ILM防止再次下沉
POST 索引名/_ilm/stop

场景2：Cold → Warm 冷层回退温层

PUT 索引名/_settings
{
 "index.routing.allocation.data_tier": "warm"
}
POST 索引名/_ilm/stop

场景3：Cold → Hot 冷层跨层直接回退热层

PUT 索引名/_settings
{
 "index.routing.allocation.data_tier": "hot"
}
POST 索引名/_ilm/stop

回流完成后恢复自动生命周期

POST 索引名/_ilm/start

边界说明

  1. Delete 已删除索引无法直接回退，只能通过快照恢复重建
  2. shrink 缩分片仅迁移节点位置，分片数量无法自动复原

5. Reindex 数据迁移重构常用命令

基础全量迁移

POST _reindex
{
 "source": {"index": "旧索引"},
 "dest": {"index": "新索引"}
}

带 Painless 脚本：字段改名、类型转换迁移

POST _reindex
{
 "source": {"index": "order_v1"},
 "dest": {"index": "order_v2"},
 "script": {
 "source": """
 if(ctx._source.containsKey('o_id')){
 ctx._source.order_id = String.valueOf(ctx._source.remove('o_id'));
 }
 if(ctx._source.containsKey('create_dt')){
 ctx._source.create_time = ctx._source.remove('create_dt');
 }
 """
 }
}

路由重打散 Reindex（解决热点倾斜）

POST _reindex?slices=auto&requests_per_second=2000
{
 "source": {"index": "order_old"},
 "dest": {"index": "order_new"},
 "script": {
 "source": """
 def suffix = Math.abs(ctx._source.orderId.hashCode()) % 3;
 ctx._routing = ctx._source.province + "_" + suffix;
 """
 }
}

异步执行 Reindex（超大索引）

POST _reindex?wait_for_completion=false
{
 "source": {"index": "旧索引"},
 "dest": {"index": "新索引"}
}

查看异步任务进度

GET _tasks/任务ID

时间范围增量追赶数据

POST _reindex
{
 "source": {
 "index": "旧索引",
 "query": {
 "range": {
 "update_time": {
 "gte": "迁移起始时间"
 }
 }
 },
 "dest": {"index": "新索引"}
 }
}

新旧索引数量校验

GET 旧索引/_count
GET 新索引/_count

6. 索引别名管理命令

创建索引同时绑定别名（初始化最佳实践）

PUT order_v1
{
 "settings": {
 "number_of_shards": 9,
 "number_of_replicas": 1
 },
 "mappings": {
 "properties": {
 "orderId": {"type":"keyword"}
 }
 },
 "aliases": {
 "alias_order": {}
 }
}

事后给已有索引添加别名

POST _aliases
{
 "actions": [
 {"add": {"index": "order_v1", "alias": "alias_order"}}
 ]
}

原子切换别名（重构无感切流/回滚核心）

POST _aliases
{
 "actions": [
 {"remove": {"index": "order_v1", "alias": "alias_order"}},
 {"add": {"index": "order_v2", "alias": "alias_order"}}
 ]
}

查询别名绑定关系

GET _alias/alias_order

删除别名

POST _aliases
{
 "actions": [
 {"remove": {"index": "*", "alias": "alias_order"}}
 ]
}

}

GET 索引名/_settings?filter_path=*.data_tier

10. 批量回流 Shell 脚本（通用可修改）

脚本1：批量所有 Warm 索引回迁 Hot（warm_to_hot.sh）

#!/bin/bash
ES_HOST="http://127.0.0.1:9200"
# ES_USER="elastic"
# ES_PWD="你的密码"
INDEX_LIST=$(curl -s "$ES_HOST/_settings/index.routing.allocation.data_tier:warm" | jq -r 'keys[] | select(startswith(".") | not)')
if [ -z "$INDEX_LIST" ];then
 echo "无warm索引需要回迁"
 exit 0
fi
echo "$INDEX_LIST"
while read index; do
[ -z "$index" ] && continue
curl -s -X PUT "$ES_HOST/$index/_settings" -H "Content-Type:application/json" -d '{"index.routing.allocation.data_tier":"hot"}'
curl -s -X POST "$ES_HOST/$index/_ilm/stop"
echo "$index 已设置hot并暂停ILM"
done <<< "$INDEX_LIST"
echo "执行完成，查看迁移进度：GET _cat/recovery?v"

适配 Cold 批量回流只需修改一行过滤条件

INDEX_LIST=$(curl -s "$ES_HOST/_settings/index.routing.allocation.data_tier:cold" | jq -r 'keys[] | select(startswith(".") | not)')

脚本使用方式

# 安装依赖
yum install jq -y
# 授权运行
chmod +x warm_to_hot.sh
./warm_to_hot.sh
